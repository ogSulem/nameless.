#  * OpenCV must be pinned to 4.x. Unpinned, pip resolves opencv-python-headless 5.x,
#    which has no `cv2.CascadeClassifier` → `import app.main` dies in a fresh image.
#  * OpenCV 4.10 wheels are built against numpy 1.x, so numpy must stay <2.
#  * aiogram 3.15 pins pydantic <2.10; the bot is tested on aiogram 3.31.
# CI installs this file, imports app.main and builds the Docker image.
